Panduan Aplikasi SI-KOMPETENSI

Satpol PP & Kebakaran Kab. Trenggalek • Terintegrasi SIMPEG

Tentang Aplikasi

SI-KOMPETENSI adalah Sistem Informasi Pengembangan Kompetensi Pegawai di lingkungan Satpol PP & Kebakaran Kabupaten Trenggalek. Aplikasi ini digunakan untuk mendata kompetensi (diklat/sertifikasi) pegawai, mengelola riwayat laporan, serta menyajikan analisa pengembangan SDM — dengan data pegawai, jabatan, dan unit kerja terintegrasi langsung (read-only) dari SIMPEG. Login menggunakan akun resmi melalui SI-Platform (Single Sign-On).

Fitur Utama

Dashboard

Statistik kompetensi & laporan, grafik distribusi pegawai per unit, dan status jabatan.

Riwayat Laporan

Kelola laporan berkala pegawai: buat, ubah, hapus, verifikasi admin (setuju/tolak), serta ekspor Excel/PDF.

Analisa Kompetensi

Analisa otomatis per tahun/bulan: ringkasan eksekutif, distribusi jenis kompetensi, temuan & rekomendasi (unduh PDF).

Master Data

Tab Data Kompetensi (input diklat/sertifikasi + verifikasi) serta referensi SIMPEG read-only: pegawai, jabatan, unit.

Profil Saya

Data kepegawaian Anda dari SIMPEG (read-only) + pemeliharaan kontak: alamat, nomor HP, dan email.

Pengaturan Admin

Parameter sistem yang dapat diubah administrator tanpa deploy ulang.

Alur Status Verifikasi

Data kompetensi dan laporan baru diverifikasi oleh administrator menjadi:

  • Disetujui — data valid dan diterima.
  • Revisi (kompetensi) — perbaiki sesuai catatan verifikator, lalu simpan kembali.
  • Ditolak (laporan) — tidak dapat diterima; alasan tertera pada catatan verifikator.
  • Draft (laporan baru) — belum diverifikasi.

Cara Menggunakan

  1. 1Input kompetensi: buka Master Data → tab Data Kompetensi → Tambah Kompetensi → isi jenis, nama diklat/sertifikat, penyelenggara, JP, dan tanggal → simpan.
  2. 2Membuat laporan: buka Riwayat Laporan → Buat Laporan → isi periode, nama laporan, pegawai, unit & jabatan → simpan (status draft).
  3. 3Tunggu verifikasi administrator; bila diminta revisi, baca catatannya, perbaiki, lalu simpan kembali.
  4. 4Pantau perkembangan pada Analisa Kompetensi dan unduh hasilnya sebagai PDF bila diperlukan.

Tanya Jawab

Mengapa kompetensi saya belum tampil sebagai "disetujui"?

Setiap input baru menunggu verifikasi administrator. Status hanya berubah melalui proses verifikasi.

Mengapa saya hanya bisa mengelola data milik sendiri?

Sistem melindungi kepemilikan data: pegawai hanya dapat mengubah/menghapus datanya sendiri; administrator dapat melihat semuanya untuk verifikasi.

Data pegawai/jabatan/unit saya salah — bagaimana memperbaikinya?

Data tersebut berasal dari SIMPEG (read-only). Hubungi pengelola kepegawaian untuk perbaikan di sistem sumber.

Sesi saya berakhir / diminta login ulang terus?

Sesi mengikuti tiket SSO SI-Platform. Masuk kembali melalui tombol "Masuk via SI-Platform"; jika berulang, hubungi administrator aplikasi.
